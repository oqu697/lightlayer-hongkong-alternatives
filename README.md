## 你现在这台阿里云香港，究竟卡在哪

阿里云香港轻量最容易被低估的问题不是性能，是“买不到”和“算不清”。

买不到：香港地域的轻量应用服务器每日 0 点限量售卖，可能当天就售罄。这不是预算问题，是库存问题，赶项目上线时很要命。

算不清：轻量的带宽是峰值上限，不是承诺指标，业务高峰期资源争抢时会被限制。对带宽有强保障诉求，官方给的路子是 ECS 固定带宽，那已经不是轻量的价格区间了。

流量口径在不同资料里对不上。2026 年 10 月的一篇社区评测写香港轻量三档统一 30Mbps 峰值，月流量 1024GB / 2048GB / 3072GB，超额 1 元/GB，2核1G 288 元/年、2核2G 408 元/年、2核4G 804 元/年；另一些页面写的是 200Mbps 峰值、不限流量。两种说法隔了半年多，配置大概率调整过。不管哪个版本，结论一致：峰值带宽会限流，超出套餐流量要另外掏钱，香港的超额单价比内地贵。下单页显示的数字才算数。

剩下的限制写在产品对比文档里，买之前很少人细看：默认固定公网 IP 不可更换；不支持 IPv6；只能挂一块数据盘；不支持二次虚拟化、弹性伸缩、部署集；同账号同地域的轻量和 ECS、RDS 默认内网不互通，要手动配置。到期不续费会自动停机，超过保留周期后实例、快照、自定义镜像一起被释放，找不回来。

线路这一项最容易被忽略。香港轻量属于国际型规格族，走 BGP_NCO（非中国优化），内地访问延迟高于大陆节点，丢包率也更大。深圳电信方向的实测平均 30–55ms，晚高峰有波动；代理商口径的北京方向测试是 35–45ms。想靠 ECS 解决回国延迟，要选 BGP（多线）精品，普通 BGP（多线）回国仍要绕行国际运营商出口。

## 迁移前后容易出事的几个细节

免备案不等于不用实名。香港节点不需要 ICP 备案，域名改个解析就能用，这是选它的理由。但阿里云侧购买要实名认证，换到境外商家，注册资料和支付方式（第三方促销信息显示支持信用卡、PayPal、支付宝和加密货币，结账页再确认一次）要提前准备好，别到付款那一步卡住。

迁之前先在阿里云做快照，并把数据导一份到本地。轻量到期停机后，超过保留周期实例和快照一起释放，这是不可逆的。

Windows 镜像要注意系统盘。阿里云香港轻量入门档 40GB 刚好卡在 Windows 的最低要求线上，选 60GB 或 80GB 更稳。

## FAQ

**阿里云香港轻量内地访问到底多少延迟？**
深圳电信方向实测 30–55ms，晚高峰有波动；北京方向代理商测试 35–45ms。它走 BGP_NCO 非中国优化线路，延迟和丢包都高于大陆节点，这是线路属性，不是配置问题。

**30M 峰值带宽够不够用？**
30Mbps 理论下载约 3.75MB/s。日 PV 几千的图文站、企业展示页够用；视频、大文件下载、图片站不够。注意峰值不等于随时能跑满。

**换到香港节点，原来的备案怎么办？**
香港不需要 ICP 备案，域名直接解析到新 IP 即可。原来在大陆做过的备案不会因为解析改到境外而自动注销，但对你这个站不再起作用。

**LightLayer 能退款吗？**
